# Accendis App Showcase

Build the Accendis homepage using the attached image as the visual reference. Focus on the frontend design first, using sample data.

Match the typography, generous whitespace, orange-and-blue ribbon, varied card sizes and category colours. Keep the top navigation removed. Use Lorem ipsum for supporting copy, retaining the app names and category names.

Include All, Personal, Home, Work and Business filters, plus the role dropdown. Make these work with local sample data. Create a responsive layout for desktop, tablet and mobile.

Structure the page with reusable components so we can add functionality incrementally. Do not add a database, authentication, payments or external integrations yet.
